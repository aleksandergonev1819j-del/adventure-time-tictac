# Adventure Chess Time

Design a modern and attractive application for sea chess with inspiration from the animation "Adventure Time" by Cartoon Netlurk. For the pieces with which sea chess is played as "X" and "O" do the following: instead of the traditional "X" and "O" to be the heads of the cartoon characters from the animation "Adventure Time", including the following characters: Finn the Human, Jake the Dog, BMO, Ice King, Princess Bubblegum, Marceline the Vampire Queen, Flame Princess, Earl of Lemongrab, Lady Rainicorn. When starting the game, it should be able to ask the user whether he wants to play against the computer or another player, and the background behind it should be thematic and inspiring to the animation "Adventure Time". When choosing to play against the computer, it should be possible to choose the complexity of the computer's thinking, whether "Easy Mode" or "Difficult Mode". After that, once one of these game modes has been selected, whether to play against a computer or against a person, the next menu opens, if a game against the computer is selected, the player can choose which one to play with, whether with "X" or "O". Do the same when choosing the mode to play "player against player". Know that you will follow the rules of sea chess: the player or the computer with "X" always starts first. For each game session, make points to count who has beaten the other how many times. After each game is finished, reload the game with the selected user game mode. Make a box on the side where you can go back to the game's home menu. Of course, after each game session is finished, display a message on the screen saying who the winner is, but if there are cases where they are equal, display on the screen that no one is the winner and that they are equal. And to supplement it after each game session and count the cases in which the players were tied.
